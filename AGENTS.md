# Skills — Agent Rules

Shared agent skills library (markdown SKILL definitions, helper scripts, prompts).

- **No build step.** Files are read directly by Claude Code / agents at runtime.
- **Naming:** keep skill folders kebab-case, with a `SKILL.md` describing trigger conditions.
- **Cross-repo use:** other ventures may symlink or reference this directory — do not reorganize folder names without a migration plan.
